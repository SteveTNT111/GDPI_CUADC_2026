## 5. 投放专项：哈工大方法研究结论 + 我们的动作清单

【仓库事实】`哈工大的CUADC资料/` 里没有正式标定文档，方法散在 `code/2025code/*.cpp` 注释与 README；**也没有弹道公式**（他们的仿真明确不建模水瓶下落/投放延迟）。所以"研究哈工大"的可抄点是工程习惯，不是公式：

| HIT 做法（出处） | 含义 | 我们今天的动作 |
|---|---|---|
| PWM 1950 开 / 1300 中位，"取决于舵机摇臂安装角"（`code2.cpp` 头注释） | 开度不可照抄 | T4 实测 A/B 可靠开/关 PWM，核对 `pwm_open/pwm_close` |
| `camera_offset1=(-0.055,-0.03)`、`camera_offset2=(0.055,0.03)` 先减再瞄准（`code7.cpp` 758/916/1306） | 相机轴与投放口有 ~5cm 级固定偏差，要补偿 | 核对 `crosshair_offset_m`/`dual_offset_m`/`front_dropper` 与实机几何；实投固定偏时按此改 |
| 桶口平面 -0.3m（相对 RTK）求交（`code7.cpp attitude_correction`） | 瞄准算桶口平面不是地面 | 我们悬停垂直投放，用相机系对准即可，不移植射线求交 |
| 触发 <5cm 持续 1s + 高度误差 <0.2m（`code7.cpp is_stable_arrival`） | 稳定判据偏保守 | 我们 `aim_cam_align_threshold_m=0.03`、`stable_time_s=0.5`；实投前建议把 stable 提到 1.0s 对照一轮 |
| code5："图像存在延迟 → 桶位置始终不太对"，限速效果不佳 | 延迟是系统误差 | 检查瞄准段速度与滤波窗口；接近速度再降一档做 A/B |
| code6："两点距离大、姿态变化大 → 定位差；多设点限速后投进" | **速度/姿态越小越准** | 我们已有 COARSE/FINE/FINAL；P5 优先调速率类参数 |
| code7：姿态补偿"效果不佳" | 不要当天加新数学 | 保证悬停平稳即可 |
| code8/code9：远点用经纬度防罗盘漂移 | WGS84 发点 | 我们已是 WGS84 航点 |

**结论**：当天投放优化的顺序 = **稳定判据 → 接近速度 → 几何偏移 → 高度**。

## 8. 航向角：写死 vs 锁存（回答文档第 18 / 62 行）

**先回答"会不会损坏程序"：不会。** 写死只影响两地坐标解算方向和搜索图形旋转；GUIDED 飞的是 WGS84 航点，不依赖机头。唯一风险是**值写错**（错题 #73：残留仿真 90° → 起飞右偏航）。

- **方案 A（保守，当天保底）**：保持 `drop_zone_bearing_deg=-1`；操作手把机头对准场地中线；起飞前核对任务摘要"锁定航向 ≈ 机头"（`plan_waypoints()` 内置 >30° 告警）。
- **方案 B（写死，推荐与 A 并用）**：现场实测"起飞点 → 投放区/侦察区中线"的方位角（手机指南针 / MP 地图量 / 两点 RTK 坐标算），填入 `drop_zone_bearing_deg`。这样不用对机头，"直接下达指令"；同时保留 A 的目视核对作交叉检查。
- **方案 C（Enter 后锁存，时间够再做）**：把 `plan_waypoints()` 移到 Enter 授权之后（或 Enter 后重算一次并重新打印摘要），这样操作手摆好飞机再回车，锁存的就是最终位姿——对应你 10-06 写的"按下 enter 后才自动锁存起飞点坐标/航向"。代价：Enter 前只有预览摘要；改动需离线 + 仿真回归。
- **建议**：当天 = **B + A 交叉核对**；C 只有在 P1 夜里有空且回归通过才上。
